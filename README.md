
# Dynamic Mobile Prototype

This project is an interactive mobile UI prototype. It is intended for validating screen flow, tap targets, navigation, and basic mobile behavior, not as production front-end application code.

The original Figma project is available at https://www.figma.com/design/dM53yYBjXlTddveHyqasmG/Dynamic-Mobile-Prototype.

## Prototype Scope

The app keeps a fixed mobile viewport, sample content, and local route transitions so reviewers can exercise the main community, group, event, post, reply, and story creation flows.

Generated Figma import files are kept in `src/imports`. The hand-authored prototype behavior lives mainly in `src/app`.

## Running Locally

Run `npm install` to install the dependencies.

Run `npm run dev` to start the local prototype server.
